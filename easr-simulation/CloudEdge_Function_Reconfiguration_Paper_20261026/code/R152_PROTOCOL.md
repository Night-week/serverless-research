# R152 有停止条件的连续局部修复：本地正式模拟

日期2026-10-25；在确认集运行前冻结。R151原始结果/权重不修改。

## 目标与范围

检验同一连续事件环境中允许提前停止的两步PPO，是否优于强制两步，并与重新充分训练的单步PPO比较。只验证第二层机制，不改变第一层随机森林，不宣称整个层次控制器或生产系统验证。

沿用R151执行器：四函数；链/汇合/树三种图；边缘1核、云3核；60秒随机分段泊松到达，所有请求排空；t=0决策，第二次最早t=15且前次部署完成。动作是单包二分或完整包迁移，排除已访问布局。切换暂停新请求接入，旧请求排空后部署，所有等待计入响应，核/链路时间线保留。内存只要求旧布局/新布局各自可行，不模拟双版本并存；不等价于真实无缝迁移。所有方法观察相同信息。

R151的65维特征增加两个共享历史输入：上一分钟到当前的滚动请求率、最近10秒请求率（观测窗口包含独立生成的决策前60秒历史）；总67维。决策前历史只作为观测，不伪装成仍驻留的请求。未来到达不进入特征。本轮所有策略从零训练，非旧100维冻结权重单因素对照。

## 数据、预算与训练

- 新生成48个训练配置、12个验证配置、24个确认配置；每配置4个初始可行布局。三组配置ID不交叉，均与R151 ID不同；同分布参数确认，不是新应用/大规模泛化。
- 模型种子17/29/43/59/71；CPU单线程模型、最多2个任务并行。
- single：最多1动作，保持=停止；stop：最多2动作，保持=停止；forced：存在合法非保持动作时不能提前停止，最多2次调整；无动作/超过窗口则结束。
- 每模型4096条完整训练仿真轨迹，所有方法使用同一配置/初始布局/请求流顺序。按完整轨迹/请求负载匹配；不声称策略决策次数、梯度样本数或墙钟完全相同，全部实际记录。
- MLP候选编码67→32→16，池化critic，普通clipped PPO；Adam .0003，8轨迹一批，4次更新，clip .2，value .5，entropy .01，grad norm .5，gamma1、GAE .95。终局reward=-平均响应/100，中间0。不加安全模块、GNN或GRU。
- 固定检查点512/1024/2048/4096。验证集每状态2流，以验证平均响应最小选择（平局取较早）；仅选检查点，不在确认集挑选参数/模型种子。最终检查点也保留。确认每状态3流；5个模型分别报告，不做推理集成。
- 每512轨迹原子保存模型、优化器、已完成轨迹、训练日志、输入/协议/源码哈希及耗时，可断点恢复。

## 主要与次要评价

主比较stop vs forced；同时报告stop vs single。主指标全窗口请求平均端到端响应，P95先逐流计算再等权平均。以配置为单位配对bootstrap95%CI，5000次（保留配置下所有布局/流/模型记录）。报告5个模型方向，不把模型重复当环境独立样本。

预设性能支持条件：stop较forced平均响应改善≥5%、配置配对CI下界>0、至少4/5种子改善、P95不退化。未满足则不得称稳定优越；对single单独判断。

风险不要求零误判：分别报告相对保持、相对single的>10%退化频率、绝对多耗时>5秒频率、最大损失、严重损失总额/总收益；不得仅用平均值掩盖严重错误。风险指标为事实边界，不在看过确认结果后临时添加安全模块。

归因：保留stop已选择第一步、取消后续动作重放，检查第二步实际净影响；该反事实不是独立训练单步基线。统计初始停止、第一步后停止、执行第二步及其胜负/最坏退化。
